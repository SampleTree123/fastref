# 真实数据15例：四模型对比

下载本目录全部内容，双击 index.html 即可查看。不要只下载网页。

- CoinVE 10例：人物衣着、背景、宠物、汽车内饰、物品、灯光等。每条原有的两到三项指令一起执行，没有拆成多轮。
- TripVVT 5例：上装2、下装1、连衣裙2，提供原来的服装参考图。
- 四列是 LTX 主配置A（849步LoRA、dev40步）、H3 PDD8、VACE LightX2V4、LTX蒸馏基座8步无训练LoRA。
- 全部60个模型视频来自已完成的正式300例推理，输入、prompt、参考、时间窗口和文件哈希已核对。本次只选例与制作网页，没有重跑推理。
- records/保存原始推理记录；manifest.json记录每个视频的来源与校验值。H3和VACE来自师兄服务器回传结果，其条件组织及参数保留在记录中。
- media/包含原视频的实际测试片段、真值片段、参考图及四个输出，全部是普通文件，没有外部软链接。原视频与真值按冻结帧号取帧；输出文件保持原样。服务器上重复输出使用硬链接，不重复占用内容空间。
- 点击“从头同步播放这组”并排看同一时段；H3原生帧率和分辨率不同，末尾的额外对齐帧不纳入共同片段同步播放。模型输出未做裁剪或重编码。

这些是效果展示案例，不是重新抽样的完整指标测试集，也未按模型表现挑选。
