## 每轮如何工作

Qwen先读全部简短视频卡和过程记录，选择实际视频编号。有疑问时可查看最多三个历史视频；本轮编辑参考不进入历史选择阶段。之后整理英文编辑指令、保留全部当前参考，调用LTX。生成后先只看结果视频，保存它自身的属性卡；再另行对照源视频、原请求、实际执行要求和参考，记录前后变化。这一步不能改写属性卡。识别不清的地方保留不确定；不自动反复生成。

工具参数或输出格式有错误时允许一次纠正。仍失败则记下该案例并继续其他案例，不默认改成最新视频。LTX仍使用40步、文字CFG3、STG1、rescale0.7、参考CFG1和seed42；本轮不顺便增加推理参数消融。

## 如何理解评价

理解测试使用UE合成数据中的真值历史视频，由Qwen生成信息卡后再选起点；不把数据集真实属性写成“模型观察”。模型可见输入与答案文件分开。此前依赖“选择参考图”的题不符合新规则，不直接拿掉图片后继续评分。

完整生成链分开报告运行成功、按预期路线选起点、指令整理和编辑结果。生成属性漂移可能让内容指代变得不明确，因此与原脚本编号不一致不一定等于语义选择错误，需要结合实际视频查看。Qwen自己的检查记录用于展示和辅助分析，不直接当成独立的人类质量评测。

本目录保留固定配置、原始工具回答、每轮记忆、生成视频及结果报告。模型和原始数据继续引用，不重复复制大型权重。
