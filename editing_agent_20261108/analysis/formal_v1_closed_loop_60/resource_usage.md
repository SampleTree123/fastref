# 前60条链的Qwen输入和耗时

范围：60条完整链，1090次实际模型调用，包含4次纠正。这里统计Qwen，不包含LTX生成视频的时间。

| 工作 | 调用数 | 输入token中位数 / 最大 | 输出token中位数 / 最大 | 单次总耗时中位数 | 已分配显存最大值 |
|---|---:|---:|---:|---:|---:|
| 观察原视频 | 60 | 2830 / 2830 | 218 / 251 | 10.79秒 | 51.95GiB |
| 整理编辑文字 | 256 | 811 / 878 | 113 / 169 | 5.42秒 | 51.36GiB |
| 单独观察生成视频 | 256 | 2830 / 2830 | 212 / 295 | 11.22秒 | 51.95GiB |
| 比较生成结果 | 260 | 5934 / 9804 | 208 / 314 | 11.08秒 | 53.99GiB |
| 选择起点 | 258 | 1807 / 9104 | 30 / 36 | 1.58秒 | 53.71GiB |

输入token包括这一轮的文字、工具说明和视觉内容，不只是用户的一句话。选择起点通常只读内容卡；主动查看历史的调用也计入选源阶段，因此最大值可能明显较高。

显存是PyTorch记录的已分配值，在输入准备之后开始统计；不是整卡占用，也没有覆盖准备阶段峰值。耗时来自每次调用记录，多卡同时工作，不能把所有秒数相加当作整批等待时间。

这些数据描述本轮成本，不证明可以无限增加编辑链长度。原始调用路径和分阶段完整数值见[JSON](resource_usage.json)。
