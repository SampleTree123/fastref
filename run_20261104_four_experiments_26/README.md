## 文件怎么用

- `preview/index.html`：现在可看、可整目录下载的四组页面。已包含52条输出，另52个位置待生成；139个媒体文件为实际文件，CoinVE源视频使用H.264展示副本。
- `manifest.json`：四组检查点、数据、配置和已有结果的位置。
- `cases.json`：昨天26例的原样副本。
- `inference.json`：共同推理参数。
- `legacy_config.yaml`：首轮682步模型的历史配置副本；数据地址指向当前原多图，图片通过显式兼容入口恢复旧尺寸。
- `contact_config.yaml`：正在训练的拼图实验配置副本。
- `run.py`：跳过已完成实验，仅生成缺少的两组；更新统一页面并导出最终`display/`。
- `launch.sh`：在用户提供的空闲GPU任务内运行，不自行申请或释放资源。
- `preflight.json`：CPU核对结果；尚不代表新增图片兼容入口已通过实际GPU编码。
- `state.json`：本批进度。
